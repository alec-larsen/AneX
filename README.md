# AneX
Current working repository intended for my NHL statistical modeling work. Currently in early transition from personal project to portfolio-ready state.

## A Few Brief Notes
1. This repository is still in the early stages of setup. While most of the vital pieces of my work should be present, a few small modules may be absent

2. For information on some of my thoughgt process behind AneX, please refer to the manual in this repository (AneX Manual.html). **This document is currently under development, but will be updated promptly as sections are added/modified**.

3. This project is not a complete/final version. Beyond the fact that I have already determined several areas for improvement (home-goal differential prediction and aggregate statline generation algorithm among others), I follow the philosophy that there is always a way to make my work better.
